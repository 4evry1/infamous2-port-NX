# image 211 (jobmod_87926738de5c_e4640): the 64 x 64 grid simulation of the water (switch/natives/job211_native.c, written
# for this port). 0x45F8 is the normal-map stage: the tables, the spectrum and the two transform passes (it calls them

# 2-D transform that 0x80B8 runs (0x80B8 itself stays lifted): 0x54E8 the bit reversal of the rows, 0x6EB8 the column
# transform, 0x5118 the bit reversal inside each row, 0x7860 the real-transform step of each row, 0x67A8 the row
# transform (0x80B8 ends in it; it is reached as a tail call). Together they were 1.0% of the busy samples lifted.
# PS3_NATIVE_J211=0 in env.txt turns all of it off, =2 is a check run against the lifted functions,
# PS3_NATIVE_J211_PASSES=<hex mask> chooses the hooks (3F all, 0 none, bit 0 0x40E8 ... bit 5 0x67A8).
